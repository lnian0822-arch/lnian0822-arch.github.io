01 / 项目命题

周年庆营销视觉

围绕品牌周年庆节点，打造具有高级感、仪式感和传播记忆点的品牌视觉体系。

设计思路

从传统活动营销视觉出发，重新构建品牌周年庆视觉语言。通过人物IP建立、场景视觉开发、海报延展和AI动态视频，形成完整视觉资产。

视觉关键词

红毯盛典 / 高级礼服 / 聚光灯 / 荣耀时刻 / 品牌记忆

02

人物IP建立

根据周年庆主题建立视觉人物IP，以高级感、明星感、品牌代表性与传播识别度为人物定位。以统一人物形象为基础，开发不同场景中的造型与状态。

人物定位

以“艺星星”虚拟人物作为视觉起点，统一面部识别、短发造型与红色礼服，建立可延展的人物资产。

红毯造型

红色礼服、聚光灯与品牌盛典氛围共同构成人物的红毯造型。通过红毯视觉语言建立人物高级感，使人物成为周年庆视觉核心。

颁奖典礼造型

以正式礼服、幕布舞台与后台准备场景呈现荣耀时刻，强化人物权威感和品牌仪式感。

晚宴造型

以晚宴空间、暖色灯光和社交状态延展人物不同面貌，使IP具有完整故事性。

03

海报延展

基于人物IP和主视觉体系，延展活动传播物料。保持人物、色彩与视觉语言统一，形成从人物视觉到主KV、再到活动传播的完整设计逻辑。当前展示已提供的周年庆预售政策海报系列。

主视觉与政策信息

以代表性预售卡呈现主视觉与权益信息的结合：人物建立识别，标题承接周年庆主题，底部信息区组织活动权益。

系列海报延展

沿用人物、标题与权益区域的统一关系，通过场景和人物状态变化形成系列。

04

AI动态视频

基于静态人物视觉，进一步开发动态影像内容。通过人物动作设计、镜头运动、灯光变化与场景转换，将平面视觉延展为动态品牌内容。
